# 四边形尺寸均衡松弛（Balanced）

2026-10-29：Balanced 已成为唯一正式松弛实现。`HexGrid.RelaxGrid(...)`、网格生成器、统一建筑演示和地形演示均使用该算法。原实现封存于 `Assets/Scripts/Hexagonal/Editor/Archive/LegacyQuadRelaxation.cs`，仅供 Editor 历史复现，不进入 Player 构建。

正式切换后的回归包含建筑、地形、网格拓扑、WFC、变形、历史算法基线复现及默认入口验证：121 项通过，0 失败。结果见 `Logs/UnifiedGridDemo/tests.xml`。

`QuadMeshOptimizer` 在固定拓扑上优化规范顶点的 XZ 位置，Y 坐标保持不变。它可替换原来的逐面松弛，仍在建层、Cell 构建和 WFC 之前执行。

## 启用

`UnifiedGridBuildingDemo` Inspector：

- `Relax Iterations` 默认 30，也可以提高到 100。
- `Preserve Boundary` 默认关闭，允许边界和孔洞轮廓一起移动；需要保持原始轮廓时开启。

代码：`demo.ConfigureRelaxation(100, false)`，需要在初始化前调用。Inspector 和代码接口都已移除算法选择项。

正式入口：`grid.RelaxGrid(100, preserveBoundary: false)`。需要统计结果或自定义权重时，使用 `grid.RelaxBalanced(100, preserveBoundary: false)`，返回接受步数、回溯次数、初末能量、面积变异系数、面积范围与总体面积变化。二者使用同一个优化器。

## 目标与求解

每次调用固定 `A0 = 初始面积 / 四边形数`，目标边长 `L0 = sqrt(A0)`。默认能量为：

`8 × Σ(A/A0−1)² + 0.2 × Σ(L/L0−1)² + 0.3 × Σcos²θ + 20 × 面数 × (总面积/初始总面积−1)²`。

面积项限制大小分布；边长项抑制细长面；角度项鼓励接近直角；总面积项抑制全图共同膨胀或收缩。不同目标之间存在折中，单独的面积变异系数不保证每一轮都下降。

用解析梯度计算各顶点的共同移动方向，按关联面数预调节，限制单步位移，再通过回溯线搜索确定步长。所有候选位置基于同一轮旧位置计算。只有总能量满足下降条件、候选四边形保持凸性/最小面积/最小边长、候选边界无相交时才接受。

边界检查使用空间桶筛选线段对，避免每步全量两两比较。包含跨孔洞和不同区域边界之间的交叉、接触及共线重叠检查；共享同一规范端点的相邻边跳过。检查针对候选终态，没有实现连续碰撞检测，也没有对非相交但整体互相包含的独立组件做覆盖检测。因此这是面向有效生成拓扑的实验优化器，不是任意坏网格的修复器或全局注入性证明。

无效初始输入直接拒绝，不改写顶点。计算在独立数组内进行，完成后统一提交。成功移动后会清除旧层、Cell 和 KD 树；需要继续调用 `BuildLayers()`、`BuildCells()`。一次调用内目标面积固定；多次独立调用会分别从各次输入重新计算目标，不应将多次调用当作一个固定目标的分帧求解器。

历史对照菜单 `Tools > Marching Cube > Archive > Relaxation > Compare Original and Balanced`，快捷键 Ctrl+Shift+Alt+F10。输出在 `Logs/HexGridRelaxation/balanced/`：`measurements.csv` 及同一原始范围取景的 initial/legacy/balanced 线框图。Legacy 数据通过显式调用归档实现产生，不经过正式生成入口。

回归覆盖不同地图尺寸/种子下的能量下降、面积离散度改善、自由/固定边界、确定性、无效初始面拒绝、跨区域边界相交拒绝，以及均衡后多层 Cell 构建。建筑控制器的孔洞拾取、建造、WFC 和撤销/重做也使用 Balanced 模式验证。

2026-10-29 最终回归：101 项通过，0 失败。不同尺寸/种子的五组均衡测试最终面积变异系数为 3.04%～3.20%，总体面积变化在 −0.14%～+0.11% 之间。

测量只包含 `RelaxGrid` 或 `RelaxBalanced` 调用。源地图生成、合并、细分、质量统计、建层、Cell、WFC、碰撞体、渲染、文件写入均不在计时范围内。Balanced 的数组初始化、梯度计算、回溯和边界检查包含在计时内。此结果不是独立 Player 构建测试，也没有隔离其他程序负载。

采样同时记录面积变异系数和无效面，确认重复测量的几何结果一致；它是相同迭代预算的比较，不是相同输出质量的比较。100 次的 Legacy 在 12×8、48×32 仍存在之前记录的无效面，Balanced 均为 0。

本机 Mono 的 `GC.GetAllocatedBytesForCurrentThread()` 恒返回 0，无法据此比较分配量。本次原始文件中的 `allocated_bytes=0` 应视为不可用；基准工具已改为对该情况输出 −1。没有测得峰值内存，也不做零分配或低 GC 的结论。
