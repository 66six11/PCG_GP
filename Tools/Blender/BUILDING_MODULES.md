# 模块规则与实现边界

版本 2.0 已根据最新 DCC 需求重新实现。操作入口、数据约定和验证命令统一见 [README.md](README.md)。

## 需求对应

| 需求 | 实现 |
|---|---|
| 三价、四价、五价点各自预览 | 三组确定性四边形扇区，各外扩一圈，默认三层 |
| 一个核心格填入当前模块，只推导直接邻接 | 每组仅一个源网格实例；只填六个共面邻格，辅助区排除当前精确逻辑 ID |
| 屋顶下方必须邻接墙 | 检查当前格与墙的共享面 Bool、几何和双向语义；墙其他面不继续推导 |
| 未配置面按 Bool 高亮 | 混合面橙色；全空或全实面采用默认几何/空气/实心候选 |
| 规则失效、场景无解 | 注册表与视口分别定位原因，无解不替换测试对象 |
| 原模和预览实时可编辑 | 核心实例共享源 Mesh，显示层各用独立变形笼 |
| 创建、重建模块 | 根据八角状态创建规范灰模，父模型几何可选复用；重建可撤销 |
| 同 ID Bool 冲突仍可创建 | 层级 ID 与内部唯一键分离，冲突提醒不阻止创建 |
| 手动放入框后注册 | 带角标参考框定义局部坐标，确认后烘焙并绑定 |
| 候选 ID、权重默认 1 | 六面标签页、相对权重、本面归一化显示、自动反向关系 |
| 注册表按 ID 折叠、检查、悬停 | 分组树、定位源对象、面/点高亮及悬停信息 |
| 合理集合组织 | 按点分层级放入 PCG Modules 集合树 |

## 约束范围


每个 Cell 仍是八角、六面的四边形柱体。三/四/五价描述共享顶点的入射 Cell 数，不改变模块编码。2.0.1 预览仅检查当前单格和直接共面邻格的接口，不传播到第二跳，不检查辅助模型之间的约束或辅助模型的其他面。因此它是接口制作预览，不是完整场景可解性验证。未填的网格仅显示线框。

2.0.2 增加有效面门槛：旋转／镜像后的某面四角 Bool 全为 0 时直接跳过该方向，即使有显式候选也不匹配，不生成邻格；至少一个角为 1 时才进入匹配。全 1 面仍匹配。门槛仅控制 DCC 预览，不删除源模块上的规则。

当前格直接接口的相邻四角、边界轮廓和双向语义都是硬约束；基础权重与组合权重只是合法候选中的偏好。内置灰模用于未配置时的建模参考，不会替代显式指定的墙、屋顶等语义。直接邻接无候选或范围不足时保留核心模型并报告。Unity 导出的完整约束保持不变。

全空与全实状态无表面。源网格不应超出规范范围，或包含退化三角面。共享面轮廓匹配主要检查几何位置连续，不替代最终材质、法线、自交、碰撞和建筑美术验收。

## 生命周期

2.1 增加双入口：开发时 Assets/DCCSources 下 `.blend` 走 Unity 原生转换，自定义属性携带同一份规则清单和 UUID；正式交付使用现有 FBX + JSON。Blender 保存前将源网格和基础族快照放入隐藏传输集合。Unity 移除导入层级的预览对象，按 UUID 绑定和规范化网格，两种入口使用同一编译／几何校验／持久化函数。规则读取失败保留原编译结果，源文件在专用目录内通过 Unity 移动时保留编译资产 GUID。开发入口不要求用户手动导出模型。

Blender 保存源对象属性、稳定唯一键、规则、注册框及静态预览。重开后重建临时缓存。编辑事务使用原生撤销；定时刷新只重建生成显示物，不修改源网格。插件更新后应先保存工作，再重启或运行启动脚本。

本版不引入网络同步、Unity 反向编辑、多 Cell 大模块或自动建筑美术生成。旧版随机网格预览、旧双模块工作台和旧结构模板菜单已移除，原始项目模型与 Unity 地形建筑逻辑继续使用其现有资产。
