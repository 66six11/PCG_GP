# 统一网格 Demo：地形基准层、轻微起伏与 Cell 贴合

打开 Assets/Scenes/UnifiedGridBuildingDemo.unity 后按 **Play**。
菜单入口：Tools > Marching Cube > Unified Grid Demo > Open Demo。
岩石生成、岩石材质混合和岩石碰撞均不接入本场景。

## 当前规则

- **同一个地形基准层**：默认第2层（世界高度0米），整片地形在这一平面附近轻微起伏，最终偏移不超过±0.297米。
- **全地形可建筑**：全域建造网格覆盖每一个多边形及边界点。可建造性依据基准层，不按地表微小高低裁掉网格。
  青色基准层网格沿实际地表显示，因此不会被细小起伏遮住；它对应的建造数据仍保持水平，上方网格层也保持水平。
- **按数据 Cell 贴合**：建筑网格数据投影到对应的底层Cell占地，地表共享四角贴合地形基准面。
  相邻两圈网格逐渐过渡回原始起伏；没有独立矩形平台，也不追踪渲染模型的细碎轮廓。
  上层结构的投影可以扩展占地，但不会把地形高度拉到楼层、屋顶或阳台。
- **可逆约束**：原始起伏和手工地形偏移始终保留。建筑存在时，Cell下方保持贴合；
  拆除最后一个占用点后解除约束，恢复原始起伏。仍被相邻建筑共用的Cell继续贴平。
- 建筑保持第一版的自由点编辑、多处建造、加层、开口、扩建、连接和拆除方式。
  三处启动示例共用同一基准层，不再使用分别位于高台、低地上的三套地基。
- **建筑 WFC**：同状态的模型变换候选按共享面接口约束选择，支持加权最小熵坍塌、传播与回溯。
  面板可换一组模块，局部编辑保留其他独立建筑。实现和素材边界见[BuildingWfc.md](BuildingWfc.md)。

## 操作

- **建筑编辑**：在青色网格上左键拖动增删点，右键临时擦除。黄色十字为已启用点。
  Q/E切换编辑层，F在鼠标指向地面时回到地形基准层，也可点击“回到地形基准层”按钮。
- **地形编辑**：左键拖动多边形抬高/降低0.10米，或贴平到地形基准面，右键临时降低。
  每笔中同一多边形只处理一次，共享顶点影响相邻多边形。
  建筑下方也可记录地形编辑，实际表面在建筑存在时保持贴合，拆除后显示所保存的地形形状。
- **设定基准层**：Q/E选层后点击“设当前层为全域地形基准”。
  地形及全部建筑整体移动，建筑相对层高保持不变；如果高度空间不足则拒绝整个操作。
  该操作可撤销，且不会产生多个互不一致的地形基准面。
- 中键旋转，Shift+中键平移，滚轮缩放。视角归位按钮恢复初始视角。
- Ctrl+Z/Ctrl+Y或按钮撤销/重做，地形、建筑、设定基准层、清空和读取共用历史，最多64笔。

## 保存

保存内容包括地形基准层、共享顶点的原始起伏编辑和全部建筑点。
贴合后的表面和碰撞从这些数据重新生成，不覆盖原始地形数据。

新存档：Application.persistentDataPath/unified-grid-building-v3.json，包含建筑WFC种子。
读取依次尝试v3、v2、v1；旧版使用默认WFC种子42，v1各列高度转换为统一基准层附近的小幅偏移，
建筑按各列旧地形高度转换相对层数。旧文件不覆盖，重新保存写入v3。

存档使用版本和拓扑签名校验，不依赖进程内的Vertex.id。完整校验成功后才修改文档。
拒绝无效浮点数、越界顶点、重复建筑点、地下层、错误网格及无法容纳的旧版高度。

## 实现与验证

UnifiedGridDocument负责基准层、原始起伏、Cell占地约束、历史和存档。
UnifiedGridBuildingDemo负责网格显示、输入、对象池、派生地表及建筑碰撞。
建筑仅刷新脏Cell；地形约束改变后重建连续地表和碰撞。
上方建筑层始终保持水平，地形波动不会改变建筑网格顶点。

Tools > Marching Cube > Unified Grid Demo 菜单：

- Run Regression Tests：全域可建造与全Cell选点、按Cell贴地、拆除/撤销恢复、
  共享顶点过渡、基准层移动、存档往返和旧存档迁移，以及原拓扑和模型变形回归。
- Validate and Capture：验证实际网格、碰撞及生成结果，输出至Logs/UnifiedGridDemo：
  tests.xml、validation.txt、terrain-only.png、overview.png、building-layer.png、cell-contact-detail.png。

快捷键：Ctrl+Shift+Alt+F5/F6/F7，分别为测试、打开、验证截图。

## 边界

地形为单层高度场，尚无洞穴、地形悬挑或地质体积。
建筑仍允许自由点编辑形成悬空结构，尚不验证重力与结构稳定性；
地表贴合的是设定基准层上的Cell底面，并不自动升至孤立高层结构。
基准层可设为1–10，建筑编辑至第13层，第14层保持空以封闭模型。
本demo面向Unity编辑器试玩，使用基础材质。
